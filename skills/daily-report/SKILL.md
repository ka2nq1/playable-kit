# Щоденний звіт

Склади звіт про роботу за сьогодні в поточному git-репозиторії.

## Що зібрати

1. Коміти за сьогодні (усі гілки, тільки автор — поточний користувач git):
   `git log --all --since="00:00" --author="$(git config user.email)" --stat --format="%h %ad %s" --date=iso`
2. Незакомічені зміни: `git diff --stat`, `git diff --cached --stat`, `git status --short` (нові файли).
3. Якщо з назв файлів і статистики незрозуміло, що зроблено, — переглянь ключові частини диффу
   (коментарі, назви нових функцій/класів). Не читай усе підряд, лише щоб зрозуміти суть.

Якщо в аргументах передано дату (наприклад "вчора" або "2026-10-27"), бери зміни за цей день замість сьогодні.

## Формат

- Тільки список, кожен пункт починається з `- `.
- Українською, коротко: одне речення на пункт, без технічних деталей, назв файлів і пояснень.
- Дієслово в минулому часі, 1-ша особа однини: «Покращив…», «Переробив…», «Додав…», «Виправив…», «Працював над…».
- Групуй дрібні зміни в одну дію; зазвичай 5–12 пунктів.
- Без заголовків і вступу. Після списку — максимум один рядок примітки, якщо комітів за день немає
  і звіт зроблено з незакомічених змін.

Приклад:

- Покращив візуал шарів
- Покращив анімацію зафарбовування полотна
- Переробив UI
- Поліпшив візуал енд карт
- Покращив тутор
- Працював над конфігами
